# Dictionary

## What it is for

Lectures build on earlier concepts. The dictionary is the student's own glossary: a place to pin down what a term means *in this course* and to record which ideas connect to it. Those connections are how mental links form, so the dictionary stores them explicitly.

## What the student can do

- **Browse and filter** all terms by name or tag in the Dictionary panel.
- **Add a term** with the **+** button: a name, an optional tag (for example *Calculus*) and a definition. If a filter finds nothing, the panel offers to add the filtered word as a new term.
- **Open a term** to read its definition and its **linked concepts**.
- **Link concepts** to each other. Links work in both directions: linking *Laplacian* to *Function* also shows *Laplacian* under *Function*. Click a linked concept to jump to it, and remove a link with its ×.
- **Edit or delete** a term. Deleting asks for confirmation and removes the term's links too.

Term names are unique regardless of capitalisation, so the glossary does not end up with *limit* and *Limit* as separate entries.

## Relationship to the mindmap

The links between terms form a graph. The **Mindmap** toggle in the top bar opens a visual map of that graph (pan/zoom, tag filters, click a node to open it here). See [mindmap](mindmap.md).
