# Mindmap

## What it is for

The dictionary stores which concepts connect. The mindmap shows that graph: terms as nodes, links as edges, so the student can see clusters and spot isolates that have nothing linked yet. It complements the dictionary list rather than replacing it.

## What the student can do

- Open the map from the **Mindmap** toggle in the top bar (alongside **Slides**).
- **Pan and zoom** the graph (scroll/drag, or the − / + / fit controls), and drag nodes if they want to tidy a cluster.
- **Filter by tags** with multi-select chips. With no tags selected (**All**), every term is shown. With tags selected, matching terms stay full strength; terms linked to them by one hop stay visible but dimmed; everything else is hidden.
- **Click a term** to open it in the dictionary sidebar.

Links made in the dictionary appear here immediately. Unlinked terms still show when viewing all, so gaps in the map are easy to notice.
